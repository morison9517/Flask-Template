# 用語集

手順書やコードに出てくる言葉を、**ひとことで**説明します。
探している言葉は、`Ctrl + F`(Mac は `Command + F`)でページ内を検索すると早いです。

- **はじめての人**:「ひとことで」の列だけ読めば十分です。全部覚える必要はありません
- **経験者の人**:最初の「このテンプレートでの呼び方」だけ見れば、手順書の言い換えが読めます

---

## このテンプレートでの呼び方

手順書とコードのコメントでは、はじめての人にも伝わるよう、いくつかの言葉を**身近なものに言い換えて**います。
正式な用語との対応はこうです。

| 手順書での呼び方 | 正式な用語 | 指しているもの |
| --- | --- | --- |
| 箱 | コンテナ / イメージ(Docker) | `web`(アプリ)と `db`(MySQL)などの実行環境 |
| 保管庫 | ボリューム(Docker volume) | 箱を作り直しても消えないデータ置き場(DBのデータなど) |
| 金庫 | `.env`(環境変数ファイル) | パスワードなど秘密の設定。Gitには入れない |
| 割り印 | `SECRET_KEY` | セッションCookieの署名に使う鍵 |
| 整理券 | CSRFトークン | フォーム送信が本物か確かめる使い捨ての値 |
| 型紙 | 基底テンプレート(`base.html`)/ テンプレートの継承 | 全ページ共通のヘッダー・フッター |
| 穴 | ブロック(`{% block %}`) | 型紙の中で、各ページが中身を差し込む場所 |
| 島(受付の島) | Blueprint | URLの受付をファイルごとにまとめたもの |
| 受付 | ルート / ビュー関数 | URLに対応する処理 |
| 表 | テーブル | データベースの表 |
| 案内係 | Nginx(リバースプロキシ) | 公開時にアプリの前に立つ入口 |
| 計器 | 動作確認用のデモページ(`/__demo`) | 起動したとき最初に出る「セットアップ完了」の画面 |
| 買い物リスト / レシート | `pyproject.toml` / `uv.lock` | 依存パッケージの一覧 / 版を固定した記録 |

## Git と GitHub

Git と GitHub を使えるようにする手順は、Progate の記事([Windows](https://prog-8.com/docs/git-env-win) / [Mac](https://prog-8.com/docs/git-env))を見てください。

| 言葉 | ひとことで | 例えると |
| --- | --- | --- |
| **Git** | プログラムの**変更の履歴**を残す道具 | セーブポイントを何個でも作れるゲーム |
| **GitHub** | Gitの履歴を**インターネット上に置いて共有**するサービス | みんなで見られるクラウドの本棚 |
| **リポジトリ** | 1つのプロジェクトの**ファイルと履歴のまとまり** | 1冊のノート |
| **clone(クローン)** | GitHub のリポジトリを**手元にコピー**すること | ノートを丸ごとコピーして持ち帰る |
| **commit(コミット)** | 今の変更を**履歴に記録**すること | セーブする |
| **push(プッシュ)** | 手元の記録を**GitHubに送る**こと | セーブデータをクラウドに上げる |
| **pull(プル)** | GitHub の新しい記録を**手元に取り込む**こと | 他の人のセーブデータを取り込む |
| **ブランチ** | 本流から分けた**作業用の枝** | 本番のノートを汚さずに試し書きするコピー |
| **プルリクエスト(PR)** | 「この変更を本流に入れてください」という**提案** | 試し書きを見せて、清書していいか聞く |
| **マージ** | ブランチの変更を**本流に合流**させること | 試し書きを清書に写す |
| **コンフリクト** | 2人が**同じ場所を別々に変えて**、どちらを残すか決められない状態 | 同じ行に2人が違うことを書いた |

## Webの仕組み

| 言葉 | ひとことで | このテンプレートでは |
| --- | --- | --- |
| **Webアプリ** | ブラウザで開いて使うアプリ | このテンプレートで作るもの |
| **サーバー** | 頼まれたら**画面やデータを返す**側のコンピューター(またはプログラム) | 開発中は自分のパソコンがサーバー役 |
| **ブラウザ** | Webページを見るアプリ(Chrome、Safari、Edge など) | — |
| **URL** | Webページの**住所** | `http://localhost:5000/auth/login` |
| **localhost** | 「**このパソコン自身**」を指す特別な名前 | 開発中のアプリはここで動く |
| **ポート** | 1台のパソコンの中の**部屋番号**。同じ住所でも番号で行き先を分ける | アプリは `5000`、DBは `3307` |
| **HTTP / HTTPS** | ブラウザとサーバーが会話する**決まりごと**。S が付くと**暗号化**される | 公開時は HTTPS にする([DEPLOY.md](DEPLOY.md)) |
| **GET / POST** | 「見せて」と「受け取って」。ページを開くのは GET、フォームを送るのは POST | `@main_bp.get(...)` / `@main_bp.post(...)` |
| **ルーティング** | 「このURLに来たら、この処理をする」という**振り分け** | `src/web/routes.py` |
| **HTML / CSS / JavaScript** | 画面の**骨組み** / **見た目** / **動き** | `templates/` と `static/` |
| **テンプレート(画面の)** | 後から値を埋め込める**HTMLのひな型**。Flaskでは Jinja という書き方を使う | `{{ title }}` や `{% block %}` の部分 |
| **API** | 画面ではなく**データだけ**を返す窓口 | デモの Todo は `/__demo/api/todos` からデータを受け取っている |
| **JSON** | データを送り合うときの**書き方の形式**。`{"name": "太郎"}` のような形 | API の返事 |
| **ステータスコード** | サーバーの返事に付く**番号**。200=成功、404=見つからない、500=サーバーの失敗 | エラー画面(`src/web/errors.py`) |
| **キャッシュ** | ブラウザが一度読んだものを**手元に取っておく**仕組み。速くなるが、古いまま残ることがある | `Ctrl + Shift + R` で強制的に読み直せる |

| **ライブラリ / パッケージ** | 誰かが作った**便利な部品**。自分で一から書かずに済む | 料理の「市販のルー」 |
| **フレームワーク** | アプリの**骨組み一式**。決まった場所に中身を書けば動く | 「この順に具を入れれば完成」のミールキット |

| **関数** | ひとまとまりの**処理に名前を付けたもの** | 料理のレシピ1枚 |
| **変数** | 値に**名前を付けて取っておく**もの | ラベルを貼った入れ物 |
| **エラー** | プログラムが**うまく動かなかった**ときの知らせ。原因が書いてある | 赤い文字の**いちばん下**を読むと原因が分かることが多い |
| **ログ** | アプリが「今なにをしたか」を書き残す**記録** | `docker compose logs -f web` で見る |
| **バグ** | プログラムの**間違い** | — |
| **デバッグ** | バグを**探して直す**こと | — |
| **リファクタリング** | 動きを変えずに、**コードを読みやすく整理**すること | — |

## 安全のための言葉

| 言葉 | ひとことで | このテンプレートでは |
| --- | --- | --- |
| **環境変数 / `.env`** | プログラムの外に置く**設定値**。パスワードなど秘密のものもここ | `.env`(★GitHubに上げない) |
| **セッション / Cookie** | 「この人はログイン済み」と覚えておくための**小さなメモ**。ブラウザが持っている | ログイン状態の保持 |
| **ハッシュ** | 元に**戻せない形**に変換すること。パスワードはこの形で保存する | DBを見てもパスワードは読めない |
| **CSRF** | 罠のサイトから、**本人になりすまして送信させる**攻撃 | フォームに整理券(CSRFトークン)を入れて防ぐ |
| **脆弱性** | 攻撃に使われてしまう**弱点** | 部品を新しくして防ぐ(Dependabot が知らせてくれる) |

## 公開(本番)の言葉

| 言葉 | ひとことで | このテンプレートでは |
| --- | --- | --- |
| **開発環境 / 本番環境** | 自分のパソコンで作る場所 / 実際に**みんなが使う場所** | `compose.yml` / `compose.prod.yml` |

| **gunicorn** | 本番用に、**同時にたくさんの人をさばける**よう Flask を動かす道具 | 公開時だけ使う |
| **Dependabot** | 使っている部品の**新しい版が出たら知らせてくれる** GitHub の機能 | `.github/dependabot.yml` |
