# はじめての人へ

このページは、**プログラミングをほとんどしたことがない人**のための道案内です。
上から順番に進めると、**自分のパソコンで Webアプリが動き、画面の文字を自分で書き換える**ところまで行けます。

- かかる時間:**1時間くらい**(道具のダウンロードを含む)
- 必要なもの:インターネットにつながったパソコン(Windows か Mac)
- 費用:**無料**

> 開発の経験がある人は、このページは飛ばして [README の経験者向けまとめ](../README.md#経験者向け30秒まとめ) へどうぞ。

途中で知らない言葉が出てきたら、[用語集](GLOSSARY.md) を開いてください。全部そこに書いてあります。

---

## 0. そもそも、これは何?

**Webアプリ**とは、ブラウザ(Chrome や Safari)で開いて使うアプリのことです。
ネットショップ、SNS、予約サイト……どれもWebアプリです。

Webアプリは、だいたい次の3つでできています。

| 部分 | 例えると | このテンプレートでは |
| --- | --- | --- |
| **見た目**(画面) | お店の店内・メニュー表 | HTML / CSS / JavaScript |
| **処理**(裏方) | 注文を受けて料理を出す厨房 | Python(Flask) |
| **データの保管** | 倉庫・帳簿 | MySQL(データベース) |

これを全部ゼロから作るのは大変です。そこで、**3つがもうつながった状態のひな型(テンプレート)**を用意しました。
あなたは中身を書き足していくだけで、自分のWebアプリが作れます。

## 1. 道具を3つ入れる

使う道具は3つだけです。どれも無料です。

| 道具 | 何をするもの | 例えると |
| --- | --- | --- |
| **Docker Desktop** | アプリとデータベースを動かす | アプリを丸ごと入れて運べる「箱」 |
| **Git** | プログラムを取ってくる・記録する | 変更の履歴を残せるノート |
| **VSCode** | プログラムを書く | 高機能なメモ帳 |

> **Python は入れなくて大丈夫です。** Docker の箱の中に入っています。

### ① Docker Desktop

1. <https://www.docker.com/products/docker-desktop/> を開く
2. 自分のパソコン(Windows / Mac)に合ったものをダウンロードして、インストールする
3. インストールが終わったら **Docker Desktop を起動する**

画面の下(Mac は上)に**クジラのアイコン🐳**が出ていれば準備完了です。

> ★Windows で「WSL」の更新を求められたら、画面の案内どおりに進めてください。
> Docker が箱を動かすために使う、Windows の機能です。
>
> ★**Docker Desktop は、作業するときに毎回起動しておく必要があります。**
> パソコンを再起動すると止まっていることがあります。うまく動かないときは、まずクジラを確認してください。

### ② Git

Git の入れ方と、GitHub(Git の記録をインターネットに置いて共有するサービス)の準備は、
Progate の記事が画像つきで分かりやすいので、そちらに沿って進めてください。

- **Windows**:[【Windows】Gitの環境構築をしよう!](https://prog-8.com/docs/git-env-win)
- **Mac**:[【Mac】Gitの環境構築をしよう!](https://prog-8.com/docs/git-env)

記事は7つの章に分かれています。**1〜4章(インストール・初期設定・GitHub のアカウント作成・SSH の設定)まで済ませれば十分です。**
5章(練習用の push)と6章(パスワード入力の省略)は、やっておくと後で楽ですが、飛ばしても構いません。

> ★記事の画面は少し前のものなので、インストーラーの選択肢の並びが違うことがあります。迷ったら、そのまま「Next」で大丈夫です。
> ★記事に出てくる言葉(コミット・プッシュ・リモートリポジトリなど)は、[用語集](GLOSSARY.md#git-と-github) で確かめられます。

### ③ VSCode

<https://code.visualstudio.com/> からダウンロードしてインストールします。

起動したら、左の四角いアイコン(拡張機能)から **「Japanese Language Pack」** を入れると、メニューが日本語になります。

## 2. ターミナルに慣れる

**ターミナル**は、パソコンに**文字で命令する**ための画面です。
マウスでクリックする代わりに、命令(**コマンド**)を打って Enter を押します。

> 例えると、レストランで**メニューを指さす代わりに、注文を口で伝える**ようなものです。
> 最初は怖く見えますが、このテンプレートで使う命令は10個もありません。

### 開き方

- **Windows**:スタートボタンを右クリック →「ターミナル」(または「Windows PowerShell」)
- **Mac**:`Command + Space` で検索を出し、「ターミナル」と打って Enter

### 試してみる

ターミナルに次の文字を打って、Enter を押してください。

```bash
docker --version
```

`Docker version 2x.x.x` のような文字が出れば、Docker がちゃんと入っています。

同じように、次も試します。

```bash
git --version
```

`git version 2.x.x` のように出ればOKです。

> Windows で Progate の記事どおりに進めた人は、**Git Bash**(記事で入れたアプリ)で打っても同じです。
> どちらのターミナルを使っても、このテンプレートの手順は変わりません。

> ★`docker` が「見つかりません」と言われたら、Docker Desktop が起動しているか確認し、
> ターミナルを一度閉じて開き直してください。

## 3. テンプレートを手元に持ってくる

インターネット上にあるこのテンプレートを、自分のパソコンにコピーします。
この作業を **clone(クローン)** と呼びます。

ターミナルで、次の2行を**1行ずつ**打ちます。

```bash
git clone https://github.com/morison9517/Flask-Template.git
cd Flask-Template
```

- 1行目:テンプレートを丸ごとコピーして、`Flask-Template` というフォルダを作る
- 2行目:そのフォルダの中に入る(`cd` は「ここに移動する」という命令)

> **Git を使いたくない場合**:<https://github.com/morison9517/Flask-Template> を開き、
> 緑の「Code」ボタン →「Download ZIP」でも取ってこられます。
> 展開したフォルダの中でターミナルを開けば、同じように進められます。
> (ただし、後で変更の記録を残したり、仲間と共有したりするには Git が必要です)

---

## 4. 設定ファイルを作る

アプリには、パスワードなどの**秘密の設定**が要ります。秘密なので、インターネットには置いていません。
代わりに**見本(`.env.example`)**が置いてあるので、それをコピーして使います。

```powershell
# Windows の場合
Copy-Item .env.example .env
```

```bash
# Mac の場合
cp .env.example .env
```

これで `.env` というファイルができました。**中身は書き換えなくて大丈夫です。** そのままで動きます。

> このテンプレートの手順書では、`.env` を**「金庫」**と呼んでいます。
> 秘密の設定をしまっておく場所で、**インターネット(GitHub)には絶対に上げません。**

---

## 5. 起動する

いよいよ起動です。

```bash
docker compose up --build
```

**初回は3〜5分かかります。** 必要な部品を全部ダウンロードしているためです。
文字がたくさん流れますが、気にしなくて大丈夫です。

次のような行が出たら、起動完了です。

```text
web-1  | * Running on http://0.0.0.0:5000
```

> ★**このターミナルは閉じないでください。** 閉じるとアプリも止まります。
> アプリが動いている間、ここには「今なにが起きているか」(ログ)が流れ続けます。

---

## 6. データの置き場所を作る(初回だけ)

アプリが動いたら、データを入れておく**表**を作ります。
さっきのターミナルはログが流れていて使えないので、**ターミナルをもう1つ開きます。**

開いたら、`cd` でテンプレートのフォルダに移動してから、次を打ちます。

```bash
docker compose exec web flask init-db
```

`DBに表を作りました` と出れば成功です。

> 「表」は、Excel の表のようなものです。ユーザーの名前やパスワードが、1人1行で記録されます。

---

## 7. 画面を見る

ブラウザで次のアドレスを開いてください。

**<http://localhost:5000>**

「**セットアップ完了 🎉**」と出て、データベースが「**接続OK**」になっていれば、**大成功です!**

画面の下にある Todo(やることリスト)に何か書いて「追加」を押してみてください。
追加できたら、**画面 → 処理 → データベース** が全部つながって動いています。

> `localhost` は「**このパソコン自身**」という意味です。
> 今あなたが見ているのは、インターネット上ではなく、自分のパソコンの中で動いているアプリです。
> なので、他の人からはまだ見えません。

うまくいかないときは [SETUP.md の「困ったとき」](SETUP.md#5-困ったとき) を見てください。

## 8. 自分で書き換えてみる

最後に、**自分の手でアプリを変えてみましょう。** ここまでできれば、もう開発者です。

### VSCode でフォルダを開く

VSCode を起動し、メニューの「ファイル」→「フォルダーを開く」で `Flask-Template` フォルダを選びます。

> 右下に「おすすめの拡張機能をインストールしますか?」と出たら、「インストール」を押してください。
> このテンプレートで使う便利な機能がまとめて入ります。

### サイトの名前を変える

1. 左のファイル一覧から `src` → `web` → `config.py` を開く
2. 次の行を探す

   ```python
   SITE_NAME = "Flask Template Demo"
   ```

3. `"..."` の中を好きな名前に変える(例:`"はじめてのアプリ"`)
4. `Ctrl + S`(Mac は `Command + S`)で保存する

### 確かめる

ブラウザで <http://localhost:5000/auth/login> を開いてください。
**画面の左上と、ブラウザのタブに、あなたが付けた名前が出ていれば成功です!** 🎉

> 保存すると、アプリが自動で読み直してくれます。
> 変わらないときは、2〜3秒待ってからブラウザを再読み込み(`F5`)してください。

---

## 9. 終わるとき・次に始めるとき

### 終わるとき

アプリを起動したターミナルで **`Ctrl + C`** を押します。それだけです。

### 次に始めるとき

ターミナルでテンプレートのフォルダに移動して、次を打ちます。

```bash
docker compose up
```

2回目からは数秒で起動します。表を作る作業(手順6)はもう要りません。

> **見た目(HTML / CSS)を学びたいとき**は、Mozilla の [MDN Web Docs](https://developer.mozilla.org/ja/docs/Learn) が
> 日本語で無料、しかも正確です。このテンプレートの画面も、そこで学べる書き方だけで作っています。

**コツは「少し変えて、すぐ確かめる」を繰り返すことです。**
一度にたくさん書くと、動かなかったときにどこが原因か分からなくなります。
1行変えたら保存して、ブラウザで確かめる。これがいちばんの近道です。
